# kit

Multi-module Go microservice toolkit — batteries-included integrations for harmoni.

**Import path:** `kit.harmoni.dev/...`

## Structure

Each directory is an independent Go module. Pick what you need; pull only its dependencies.

## Requirements
- Go 1.23+
- Depends on `harmoni.dev/*` for core interfaces

## Modules
See [SPEC.md](https://github.com/harmonikit/harmonikit/blob/main/SPEC.md) for the full module map.
